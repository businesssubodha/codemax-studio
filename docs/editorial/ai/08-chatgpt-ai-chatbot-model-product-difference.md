ChatGPT is OpenAI's AI assistant for tasks such as writing, studying, planning and working with information. Search phrases like ChatGPT AI chatbot and OpenAI chatbot GPT point towards the same broad product, but they can also mix up the application with the models and tools behind it.

## A product is more than a model name
A model generates or interprets information. A product supplies the interface, account settings and tools around that model. When an assistant searches the web, reads a file or works with another application, those capabilities depend on the tools available in the current experience.

Do not assume an old screenshot describes your account. Check the interface and current official documentation for the feature you intend to use. Access can vary, and a feature mentioned in a product announcement may have conditions attached to it.

## Choose the right kind of task
For drafting, give the audience, purpose and source material. For explanation, describe your current level of understanding and ask for an example. For a file-based task, identify the relevant document and what you want extracted or changed.

A request such as summarise this document should also specify whether you want key decisions, an outline or a detailed account. These are different outputs. Providing that distinction at the start reduces avoidable revision and helps you judge whether the result meets the request.

## Check which evidence supports an answer
Some answers use only the conversation and model knowledge. Others may use retrieved sources or files. Look for the actual evidence provided, then open important citations and compare the claim with the source. A link is useful only if it supports the nearby statement.

For your own documents, check names, figures and dates against the original. Ask for uncertainty to be made explicit. A fluent answer can still omit a qualification or merge details from different parts of a document.

## Treat tool actions as separate outcomes
If the assistant can edit or create something, inspect the resulting file or application state. Distinguish a proposed draft from a saved change, and a saved change from something shared with another person. The same conversational wording can otherwise hide very different consequences.

Use clear instructions about the intended destination and approval point. This is particularly helpful when a task involves several files with similar names or more than one connected account. Specific instructions make the result easier to verify.

## Learn from one repeatable example
Choose a short task and keep the original input, instructions and output. Note what helped and what you corrected. That gives you a reference for future changes without treating one response as a permanent measure of the product.

This overview does not claim that every feature is included in every plan. Use OpenAI's current official documentation for account-specific setup and availability. The enduring skill is knowing what you asked for, what evidence was used and what was actually completed.
