## Exact proposed production changes

1. Add permanent 301 redirects for public GET/HEAD visits to these exact legacy marketing routes, including slashless variants:
   - `/about/` to `/#about`
   - `/contact/` to `/#enquiry`
   - `/services/` to `/#services`
   The service destination contains the current overview of all six services and links to their individual pages. These are matching replacement sections, not blanket homepage redirects. All three destination IDs are verified in the generated HTML. Redirects retain query parameters and target the HTTPS apex. Existing retired-route redirects also gain slashless coverage.
2. Correct three article links in rendered content and future imports:
   - `/blog/exploring-the-latest-innovations-in-ai-technologies/` to `/exploring-latest-innovations-in-ai-technologies/`
   - `/blog/wordpress-management-services-by-codemax/` to `/wordpress-management-services-by-codemax/`
   - `/blog/melbourne-wordpress-management-services/` to `/melbourne-wordpress-management-services/`
3. Remove malformed markup from link URL attributes while retaining readable text and the valid YouTube link. Reject the same malformed URLs in future imports.
4. Add regression checks for redirect destination/fragment existence, preserved WordPress routes, slash variants, query parameters, malformed links and the three repaired article destinations.

WordPress editor cookies, preview/search/system queries and POST requests continue to the existing origin. Article URLs, media, archive routes, original dates, DNS, credentials, contact delivery and publishing schedules are unchanged. Unknown paths are not redirected speculatively.
