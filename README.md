# CodeMax Studio

New CodeMax marketing site direction inspired by the Pace Züri reference: modular Swiss grid, kinetic route lines, oversized type and a sharp orange/ink palette.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Push this folder to a GitHub repository and import it into Vercel. The included `vercel.json` and Astro adapter are ready for deployment. `supabase/schema.sql` is prepared for enquiry storage when the form endpoint is connected.
